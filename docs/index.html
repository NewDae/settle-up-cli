Three commands. You're in.

Node.js 22+
terminal
# Install
$ npm install -g settle-up-cli

# Sign in with your Settle Up account
$ settleup auth login

# See your groups
$ settleup groups list

Production endpoints included. No API keys or backend setup.

FOR AI AGENTS

A CLI your agent
can work with.

Structured JSON output. Explicit IDs for writes. Built-in schemas for every write payload.

Sign in yourself in your terminal, then let your shell-capable agent use the CLI. Keep passwords and tokens out of the conversation.

Read the agent guide ↗Plain-text agent instructions ↗
DISCOVER → READ → WRITE
settleup --help
settleup groups list
settleup schema expenses.create

# Use exact IDs and a reviewed JSON payload
settleup expenses create \
  --group-id <groupId> \
  --input expense.json

Look up IDs first. Only make changes the user has authorized.
