01 / Connect

02 / Discover → read → write

settleup --help
settleup members list \
  --group-id <groupId>
settleup schema expenses.create

# Only after user authorization
settleup expenses create \
  --group-id <groupId> \
  --input expense.json
  • Resolve exact IDs before writes. Account uid ≠ group memberId.
  • Amounts and weights: decimal strings. Write dates: epoch milliseconds.
  • Pass JSON via --input file.json or stdin with --input -.
  • Omitted patch fields stay unchanged. Provided arrays and objects replace the field.
  • Read back writes. Don't blindly retry a create after an uncertain response.
Response contract & error recovery
{ "ok": true, "data": { ... }, "meta": { ... } }
{ "ok": false, "error": { "code": "...", "message": "...",
  "details": { ... } }, "meta": { ... } }

Stdout is JSON; failures exit nonzero. AUTH_REQUIRED or AUTH_REFRESH_FAILED: ask the user to log in. API_RATE_LIMITED: back off. GROUP_ACCESS_DENIED: confirm access and the target group.
